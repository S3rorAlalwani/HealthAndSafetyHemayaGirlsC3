# تطبيق الأمن والسلامة المدرسية
هذه نسخة أولية تعمل مباشرة من المتصفح بدون خادم أو قاعدة بيانات.
المزايا:
- لوحة تحكم.
- تفتيش يومي مع الحالات: مطابق / غير مطابق / يحتاج إلى المتابعة.
- الحوادث والبلاغات.
- المخاطر والملاحظات.
- الإجراءات التصحيحية.
- تقارير قابلة للطباعة.
- خطط طوارئ.
- حفظ البيانات محليًا داخل المتصفح (LocalStorage).

التشغيل:
1. فك الضغط.
2. افتح index.html في Chrome أو Safari.
3. البيانات تبقى على نفس الجهاز والمتصفح.
